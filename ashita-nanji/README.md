北海道七天六夜的普通人 AU 互动旅行小说。手机优先、固定剧情、不调用 AI 即时续写。

## 当前人物照片互动（V4）
- **无需捏脸**：初次填写昵称后，可自行选择两张人物参考照片，也可直接跳过进入登机牌。
- 可为旅行者和张极分别上传你有权使用的真人照片（JPG、PNG、WebP、兼容 HEIC）。
- 照片可调整缩放、水平/垂直取景，切换原片、日系胶片、冷调、黑白底片。
- 点击照片卡翻面，可写照片备注；点击故事里的微信人物头像可直接打开对应照片卡，并翻面。
- 相册中有两个人的独立人物档案；拍摄人像时可查看参考照片，但不会自动合成真实合照，也不会把旅行示意照片冒充人物照片。
- 未设置人物照片时显示文字头像，不会随意推测两个人长相。
- 人像设置和旅行选择保存在当前浏览器本地，JSON 导出的存档中也含照片数据，分享时留意隐私。
- 该版本没有图片上传服务器，也没有 AI 人像生成后端。

## 其他互动
- 写入名字后领取旅行票，支持右滑或按钮登机。
- 微信消息保持原版场景内直接显示的气泡，预设回复会改变后续剧情。
- 音乐盒堂可试听游戏合成旋律、浏览虚构商品、用试玩预算购买，商品进入背包。
- 取景器可调整构图、按快门、重拍、保留或删除游戏场景照片；这些照片是氛围示意图，并不调用手机摄像头。
- 旅行地图、背包、相册、故事记录、返回上一场景、JSON 存档导入/导出。
- 新旧存档兼容；此前保留的 2D 捏脸数据不会删除，但不再用于游戏界面。

## 保存与部署
- 昵称是本机游戏登记，不是云账号登录，无邮箱/密码。
- localStorage 保存进度，跨设备请通过 JSON 导出、导入。
- 重新开始需要确认；建议先备份游戏存档。
- 项目在 `ashita-nanji/` 独立目录，静态文件，无需安装依赖。
- 不会修改 J. PRIVÉ 手机项目或其后端。
