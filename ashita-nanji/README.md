# 明天几点出发？ | Ashita, Nanji ni Demasu ka?

北海道七天六夜普通人 AU 互动旅行故事。独立运行的纯静态网页游戏。

## 已可玩范围
- CHAPTER 00：12月17—18日，北京 / 朋友圈、私聊、出发前准备
- CHAPTER 01：12月19日，札幌 / 共进晚餐、只约小樽、独立旅行
- CHAPTER 02：12月20日，札幌—小樽 / 音乐盒、逛店、照片、是否继续同行
- CHAPTER 03：12月21日，洞爷湖抵达日 / 交通、住宿、湖畔、计划沟通
- 12月22—25日尚未制作；不使用 AI 临时生成剧情

## 玩法
打开 index.html，点击开始旅程，填写 1—16 字的名字。剧情全部使用固定台词和预设选项。底部可切换剧情、行程、相册、背包与旅行档案。

## 保存与隐私
- 名字用于本地角色档案，不需要邮箱或密码；这不是联网账号登录。
- 进度保存在当前浏览器的 localStorage，不能跨设备自动同步。
- 可在「档案」导出 JSON 存档，并在另一浏览器导入。
- 相册使用旅行氛围示意图；只有选择拍照才写入照片记录。
- 重新开始会清除本地进度，请先备份。

## 部署与项目隔离
纯静态网页，不依赖 npm。将 ashita-nanji 设为网站根目录即可部署，或从现有静态域名访问 /ashita-nanji/。
本目录独立于仓库根目录其他手机模拟器文件，不需要修改任何现有页面。

## V2 沉浸式互动升级
- 新玩家填写昵称后获得旅行票，可右滑登机牌或点击按钮进入剧情；旧存档直接继续。
- 微信消息按先后逐条查看，支持一键展开所有固定对白。
- 小樽音乐盒堂支持浏览 3 款虚构商品、试听原创合成短旋律、确认购买，使用仅供游戏的纪念品预算。
- 拍照会进入取景界面，支持选择构图、按下快门、保留或删除；不会调用手机摄像头。普通游览选项不会强制触发拍照。
- 存档继续使用相同的 localStorage 键名，允许导出 JSON 和导入已保存进度。

## V3 人物外貌参考
- 进入「档案」或「相册」的「人物外貌档案」，分别给女主、张极上传参考照片并填写简短外貌描述。
- 照片在浏览器中压缩至最长边 600px，保存在本地存档中；网站没有上传图片的服务器接口。
- 进入剧情摄影模式中的人像/合照场景，会显示所选人物的形象参考缩略图；不会把头像冒充合成的人像照片。
- 旧存档可以直接打开，参考图随 JSON 导出、导入；导出文件也含上传的图片，分享前注意隐私。
- 当前**尚未接入 AI 图片生成**，已有照片仍是静态剧情氛围图。连续生成一致人物肖像需要另行配置安全的服务端生图接口，不应将 API 密钥放入前端。

## V3 可爱挂 2D 捏脸与冬装
- 新玩家填写名字后进入原创 2D 捏脸页，然后领取登机牌、进入原有剧情。
- 旅行者可编辑肤色、脸型、眼型、瞳色、嘴型、腮红、头发长度、刘海、发色、外套、围巾与帽子；可以随机搭配和恢复默认。
- 张极使用固定卡通五官，可在预设范围内切换发型、冬季外套、围巾和帽子，不代表真实人物肖像。
- 形象会显示在档案、微信聊天气泡、相册封面和人物拍照的取景参考区域；仅作为卡通参考，不声称真人合照已经生成。
- 原来的照片参考档案作为**可选**辅助功能保留，无须上传照片也可游戏。
- 兼容旧版存档（原 localStorage 键未改变），旧玩家不会被强制回到捏脸开场。
